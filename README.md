# Дипломный проект профессии «Тестировщик»
В рамках дипломного проекта требовалось автоматизировать тестирование комплексного сервиса покупки тура, взаимодействующего с СУБД и API Банка.

База данных хранит информацию о заказах, платежах, статусах карт, способах оплаты.

Для покупки тура есть два способа: с помощью карты и в кредит. В приложении используются два отдельных сервиса оплаты: Payment Gate и Credit Gate.

## Запуск приложения
### Подготовительный этап
1. Установить и запустить IntelliJ IDEA;
2. Установать и запустить Docker Desktop;
3. Склонировать репозиторий с Github [по ссылке](git@github.com:NellyShi/qa-diploma.git).
4. Открыть проект в IntelliJ IDEA.

### Запуск тестового окружения

1. Запустить терминал в папке прокта и запустить скрипт start_env.bat. Выбрать СУБД: MySQL или PostgreSQL. Запустится
   MySQL или PostgreSQL, NodeJS.

2. Подождать когда запустится окружение. Убедиться в готовности системы. Приложение должно быть доступно по адресу:
```
http://localhost:8080/
```
Если на странице не отобразился сервис покупки тура - перезапустите start_env.bat (возможно не успели создаться контейнеры в докере).

### Запуск тестов

Запустить терминал в папке прокта и запустить скрипт start_testing.bat. Запустится тестирование.
